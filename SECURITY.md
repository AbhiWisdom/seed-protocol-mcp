# Security

**Report a vulnerability privately:** [GitHub → Security → Report a vulnerability](https://github.com/AbhiWisdom/seed-protocol-mcp/security/advisories/new). We aim to reply within 3 days.

In scope: this connector (`seed-protocol-mcp`), seed.abhibots.com and its API. Please do not access other people's data and do not run load or denial-of-service tests.

How SEED protects data, in plain words: [seed.abhibots.com/security](https://seed.abhibots.com/security) · [seed.abhibots.com/privacy](https://seed.abhibots.com/privacy).

Want no server at all? `npx seed-protocol-mcp setup --local` keeps the soul on your machine and never calls the SEED API.
